논문 정보
---------

  저자   : 신지은, 김정기, 서은국
  게재   : 한국심리학회지 사회 및 성격, 2017, 31(2), 21-38
  KCI ID : FI002229041
  PDF    : KCI_FI002229041.pdf


1. 논문 핵심 결론 (프로젝트에 쓸 포인트)
----------------------------------------

  학생들은 기숙사 만족에 영향을 주는 요인을 예측할 때
  「룸메이트의 행복」을 가장 덜 중요하다고 생각하지만,
  실제 기숙사 만족도를 가장 잘 예측하는 요인은 「룸메이트의 행복」이었다.

  → 룸메이트 매칭 시 생활 습관만이 아니라
    「행복/정서 수준」도 반드시 고려해야 함.


2. 논문에서 사용한 4가지 기숙사 요인
------------------------------------

  (1) 기본적 생활시설 상태
  (2) 룸메이트와의 생활 습관의 일치성
  (3) 주변 시설의 편리함
  (4) 룸메이트가 얼마나 행복한 사람인지

  척도: 7점 (1=전혀 아님 ~ 7=매우 그럼)


3. 추출한 수치 데이터 (표 1, 3, 5, 6)
------------------------------------

  [연구 1] 신입생 예측 중요도 (N=284)
    기본적 생활시설 상태          평균 5.37 (SD 1.16)  ← 가장 높음
    룸메이트 생활 습관 일치성      평균 5.34 (SD 1.35)
    주변 시설 편리함              평균 5.19 (SD 1.29)
    룸메이트 행복                 평균 5.17 (SD 1.34)  ← 가장 낮음

  [연구 2] 재학생 현재 중요도 (N=125)
    기본적 생활시설 상태          평균 5.47 (SD 1.36)  ← 가장 높음
    룸메이트 생활 습관 일치성      평균 5.15 (SD 1.54)
    주변 시설 편리함              평균 5.12 (SD 1.47)
    룸메이트 행복                 평균 4.54 (SD 1.81)  ← 가장 낮음

  [연구 3] 실제 평가 및 만족도 (N=77, 4개월 후)
    기본적 생활시설 상태          평균 4.66 (SD 1.65)
    주변 시설 편리함              평균 4.51 (SD 1.45)
    룸메이트 생활 습관 일치성      평균 4.57 (SD 1.63)
    룸메이트 행복                 평균 4.78 (SD 1.20)
    기숙사 만족도                 평균 5.21 (SD 1.21)

  [연구 3] 회귀분석 — 기숙사 만족도 예측 계수
    룸메이트 행복                 β = 0.41, p < .001  ★ 유의 (가장 큼)
    주변 시설 편리함              β = 0.16, p < .10   (경계)
    기본적 생활시설 상태          β = 0.14, p < .10   (경계)
    룸메이트 생활 습관 일치성      β = 0.09, n.s.      (유의하지 않음)


4. 본 프로젝트에의 매핑
-----------------------

  논문 요인                          →  프로젝트 필드 / 처리
  ----------------------------------------------------------------
  룸메이트 생활 습관 일치성          →  Smoking, Cleaning_Habit,
                                      Eating_in_Room, Noise_Sensitivity
  룸메이트 행복                      →  Happiness_Level (신규, 1~7)
                                      수면의 질·스트레스로 추정
  기본적 생활시설 / 주변 시설        →  현재 모델 미포함 (데이터 없음)

  논문 기반 기본 가중치 (회귀계수 반영):
    happiness      : 3.0  (가장 높음 — 논문 β=0.41)

    cleaning       : 2.0
    noise          : 1.8
    eating         : 1.5
