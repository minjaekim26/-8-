[2] 핵심 실행 파일
--------------------------------------------------------------------------------

■ app.py
  - 역할: Streamlit 웹 애플리케이션 (사용자가 브라우저로 접속하는 UI)
  - 실행: python -m streamlit run app.py
  - 하는 일:
      1단계) st.form 으로 본인 정보(성별, 나이, 흡연, 청소, 음식, 소음) 입력
      2단계) st.chat_input 으로 룸메이트 선호 6문항 채팅
      3단계) 매칭 결과 표 + 요약 표시
  - 사용하는 모듈: roommate_match_chat.py 에서 함수 import
      (load_dataset, parse_answer_rule, run_matching_results 등)
  - Streamlit Cloud 배포 시 Main file 로 지정하는 파일

■ roommate_match_chat.py
  - 역할: 프로젝트의 핵심 로직 (데이터, 매칭, 채팅 파싱, 터미널 루프)
  - 실행: python roommate_match_chat.py  (터미널 전용 채팅 모드)
  - 주요 구성:
      [데이터]  load_dataset(), generate_roommate_candidates(), ensure_candidate_pool()
      [KCI]     load_kci_research_weights(), compute_happiness_level(),
                estimate_happiness_level()  ← 논문 기반 가중치·행복 수준
      [매칭]    apply_filters(), match_score_weighted(), find_best_matches_for_user()
      [채팅]    parse_answer_rule(), ask_next_question(), ChatState
      [결과]    format_match_summary(), run_matching_results()
      [터미널]  chat_loop()  -- 본인정보+선호 모두 채팅으로 수집
  - 매칭 점수: 생활 습관(흡연·청소·음식·소음) + 나이·수면·활동량 +
               Happiness_Level(행복 수준, KCI 논문에서 최고 가중치)
  - app.py 와 터미널 모두 이 파일의 함수를 공유함

■ generate_candidates.py
  - 역할: 후보 5,000명 CSV 를 만드는 독립 스크립트
  - 실행: python generate_candidates.py
  - 입력: Sleep_health_and_lifestyle_dataset.csv (원본 374명, 직업·BMI 분포 참고)
  - 출력: roommate_candidates.csv (5,000명 합성 프로필)
  - 실제 생성 로직은 roommate_match_chat.py 의 generate_roommate_candidates() 사용


[3] 데이터 파일
--------------------------------------------------------------------------------

■ roommate_candidates.csv  (약 5,000행)
  - 역할: 매칭에 실제로 사용하는 확장 후보 풀
  - 사용처: load_dataset() 이 이 파일을 우선 로드
  - 포함 컬럼:
      Person ID, Gender, Age, Occupation, Sleep Duration, Quality of Sleep,
      Physical Activity Level, Stress Level, BMI Category, Blood Pressure,
      Heart Rate, Daily Steps, Sleep Disorder,
      Smoking, Cleaning_Habit, Eating_in_Room, Noise_Sensitivity,
      Happiness_Level (수면·스트레스 기반 1~7, KCI 논문 반영)
  - 생성: generate_candidates.py 또는 앱 최초 실행 시 자동 생성

■ kci_research_data.csv
  - 역할: KCI 논문(FI002229041)에서 추출한 4요인 수치·회귀계수 (기계 가독용)
  - 출처: 신지은, 김정기, 서은국 (2017). 기숙사 만족도에 대한 예측 오류:
          행복한 룸메이트의 과소평가된 가치. 한국심리학회지: 사회 및 성격, 31(2), 21-38.
  - 주요 컬럼:
      factor_id, factor_name_ko, study1_predicted_mean, study2_current_mean,
      study3_actual_mean, regression_beta, regression_p, project_mapping
  - 4요인:
      facility(생활시설), habit_match(습관 일치), surroundings(주변 시설),
      roommate_happiness(룸메이트 행복) ← 회귀 β=0.41, p<.001 (유일한 유의 예측 변수)
  - 사용처: load_kci_research_weights() 가 regression_beta 를 읽어
            happiness 가중치 등 기본값 설정 (파일 없으면 내장 기본값 사용)

■ KCI_FI002229041_추출.txt
  - 역할: PDF 논문 데이터 추출 요약 + 프로젝트 매핑 설명 (한국어, 사람이 읽기용)
  - 내용: 연구 1~3 표 수치, 회귀분석 결과, 본 프로젝트 필드 매핑, 참고문헌
  - 코드에서 직접 import 하지 않음 (문서·발표 참고용)

■ Sleep_health_and_lifestyle_dataset.csv  (374행)
  - 역할: Kaggle 기반 원본 시드 데이터
  - 사용처:
      - generate_candidates.py 가 직업·BMI 카테고리 분포 샘플링에 사용
      - roommate_candidates.csv 가 없을 때 load_dataset() 의 fallback
  - 룸메이트 전용 컬럼(Smoking 등)은 원본에 없음 → 로드 시 add_roommate_features() 로 추가 가능


[3-1] KCI 논문 연동 요약
--------------------------------------------------------------------------------

  논문 핵심: 학생들은 「룸메이트 행복」을 덜 중요하다고 예측하지만,
             실제 기숙사 만족도는 「룸메이트 행복」이 가장 잘 예측함 (β=0.41).

  프로젝트 적용:
    - habit_match(습관 일치)  → Smoking, Cleaning_Habit, Eating_in_Room, Noise_Sensitivity
    - roommate_happiness      → Happiness_Level 컬럼 (수면의 질·스트레스·수면시간 → 1~7)
    - facility, surroundings  → 현재 데이터 없음, 매칭 미포함

  기본 가중치 (load_kci_research_weights):
    happiness 2.9~3.0 (최고), smoking 2.0, cleaning 2.0, noise 1.8,
    eating 1.5, age 1.2, sleep_duration 1.2, daily_steps 1.0

  사용자 프로필의 Happiness_Level:
    폼에서 직접 받지 않음 → Sleep_Duration·기본 수면/스트레스로 estimate_happiness_level() 추정
    후보 CSV에는 Quality of Sleep, Stress Level 로 compute_happiness_level() 계산값 저장

[6] 파일 간 import / 호출 관계 (상세)
--------------------------------------------------------------------------------

  app.py
    |-- import roommate_match_chat
    |     |-- ensure_candidate_pool()     → CSV 경로 결정, 없으면 생성

    |     |-- set_profile_from_form()     → 1단계 폼 값 → profile 저장
    |     |-- start_matching_phase()      → 2단계 채팅 시작
    |     |-- ask_next_question()         → 다음 질문 템플릿

    |     |-- run_matching_results()      → 필터+점수 계산+요약
    |     |     |-- load_kci_research_weights()  → kci_research_data.csv
    |     |     |-- match_score_weighted()       → Happiness_Level 포함 점수
    |     |-- format_profile_summary()    → 입력 정보 마크다운 요약

    |-- ensure_candidate_pool()

    |-- chat_loop()
          |-- ask_next_question()         → 1단계 본인정보 6문항
          |-- parse_answer_rule()
          |-- maybe_advance_phase()       → 2단계 전환
          |-- run_matching_and_print()    → 결과 출력

  generate_candidates.py
    |-- import generate_roommate_candidates from roommate_match_chat
    |-- Sleep_health_and_lifestyle_dataset.csv → roommate_candidates.csv

--- 오프닝 (30초~1분) ---

  "안녕하세요. 오늘 발표할 프로젝트는 **룸메이트 매칭 시스템**입니다.

   자취나 기숙사에서 룸메이트를 구할 때, 나이만 보고 정하면
   생활 습관이 안 맞아서 불편한 경우가 많습니다.
   흡연 여부, 청소 습관, 방 안에서 음식 먹는지,
   소음에 민감한지 같은 **생활 성향**이 맞는지가 훨씬 중요하죠.

   그래서 저는 수면·건강·생활 습관 데이터를 바탕으로,
   **나와 잘 맞는 룸메이트 후보**를 추천해 주는 프로그램을 만들었습니다.

   GitHub 저장소 이름은 `-8-` 이고,
   웹과 터미널 두 가지 방식으로 실행할 수 있습니다."


--- 문제 정의 & 목표 (1분) ---

  "기존에 룸메이트를 구할 때는 보통
   성별, 나이 정도만 맞추거나, 지인 소개에 의존하는 경우가 많습니다.

   하지만 실제로 부딪히는 건 **일상 습관**입니다.
   담배 냄새, 청소 주기, 새벽에 배달 음식, 소음 민감도…
   이런 것들이 안 맞으면 스트레스가 커집니다.

   이 프로젝트의 목표는 세 가지입니다.

   첫째, 사용자 **본인의 생활 정보**를 먼저 받고,
   둘째, **원하는 룸메이트 조건**을 추가로 받아서,
   셋째, 수천 명의 후보 중에서 **점수가 높은 상위 5명**을 추천하는 것입니다.

   그리고 외부 AI API 없이도 돌아가게 만들었습니다.
   API 키나 비용 걱정 없이 로컬이나 무료 호스팅에서 바로 쓸 수 있습니다."


--- 시스템 구조 (1분) ---

  "프로젝트 구조를 간단히 말씀드리면, 크게 세 부분입니다.

   **데이터**, **매칭 엔진**, **사용자 화면**입니다.

   데이터는 Kaggle의 Sleep Health and Lifestyle 데이터셋을 기반으로,
   원본 374명에서 직업·BMI 분포를 참고해서
   **5,000명의 합성 후보**를 `roommate_candidates.csv` 로 만들었습니다.
   각 후보에는 흡연, 청소, 방 안 음식, 소음 민감도 같은
   룸메이트 매칭용 컬럼이 들어 있습니다.
   또한 KCI 논문(신지은 et al., 2017)을 반영해
   **행복 수준(Happiness_Level)** 컬럼과 논문 기반 가중치를 적용했습니다.

   매칭 엔진은 `roommate_match_chat.py` 한 파일에 모여 있습니다.
   `kci_research_data.csv` 에서 논문 회귀계수를 읽어
   룸메이트 행복 항목에 가장 높은 가중치를 줍니다.

   화면은 `app.py` 로 만든 **Streamlit 웹앱**입니다.
   1단계는 폼, 2단계는 채팅으로 나눴습니다."


--- 사용 흐름 시연 멘트 (1~2분) ---

  "실제로 어떻게 쓰는지 보여드리겠습니다.

   [브라우저에서 http://localhost:8501 접속]

   **1단계는 폼**입니다.
   성별, 나이, 흡연 여부, 청소 습관, 방 안 음식, 소음 민감도를
   드롭다운과 슬라이더로 입력합니다.
   여기서는 API가 필요 없습니다. 값이 바로 저장됩니다.

   [다음 단계로 버튼 클릭]

   **2단계는 채팅**입니다.
   선호하는 룸메이트 성별, 흡연 조건, 나이대,
   그리고 각 항목이 얼마나 중요한지 1에서 5까지 물어봅니다.
   질문은 최대 6개이고, 같은 걸 반복해서 묻지 않습니다.

   [예: '상관없음', '20~25', '4' 입력]

   답변은 규칙 기반으로 인식합니다.
   예를 들어 '20~25'라고 쓰면 나이 필터로 저장되고,
   숫자 하나만 쓰면 그 나이 기준 ±2세로 잡습니다.

   [매칭 결과 화면]

   입력이 끝나면 **상위 5명**이 표로 나오고,
   왜 이 후보가 잘 맞는지 요약 설명도 함께 보여줍니다.
   흡연 성향이 같다, 청소 습관이 비슷하다, 행복 수준이 유사하다
   같은 이유를 텍스트로 정리합니다.
   KCI 연구에 따르면 룸메이트 행복이 기숙사 만족의 핵심 요인이라는 점도
   결과 요약에 안내됩니다."


--- 매칭 로직 설명 (1분) ---

  "점수는 어떻게 매기냐면,

   먼저 **필터**입니다.
   사용자가 '여성만', '비흡연만', '20~25세'처럼 조건을 주면
   5,000명 중에서 그 조건에 맞는 사람만 남깁니다.

   그다음 **가중치 점수**입니다.
   흡연, 청소, 방 안 음식, 소음, 나이 차이, 수면 시간, 활동량,
   그리고 **행복 수준(Happiness_Level)** 을
   사용자 프로필과 후보를 하나씩 비교합니다.
   잘 맞으면 점수를 더하고, 많이 다르면 깎습니다.

   가중치 기본값은 KCI 논문(신지은 et al., 2017) 회귀분석을 반영했습니다.
   논문에서 기숙사 만족도를 가장 잘 예측한 것은
   「룸메이트 행복」(β=0.41)이었기 때문에,
   happiness 항목이 smoking·cleaning 보다 높은 가중치를 갖습니다.

   사용자가 '흡연이 매우 중요하다'고 하면
   흡연 항목의 가중치가 커져서, 흡연 불일치 시 점수 페널티도 커집니다.

   최종적으로 점수 상위 5명을 추천합니다."


--- 기술 스택 & 파일 (30초~1분) ---

  "기술 스택은 **Python**, **Pandas**, **Streamlit** 입니다.
   AI API는 쓰지 않습니다.

   주요 파일은 다음과 같습니다.
   - `app.py` : 웹 UI
   - `roommate_match_chat.py` : 매칭·채팅·데이터 로딩
   - `roommate_candidates.csv` : 5,000명 후보 데이터 (Happiness_Level 포함)
   - `kci_research_data.csv` : KCI 논문에서 추출한 가중치 근거 데이터
   - `KCI_FI002229041_추출.txt` : 논문 수치·매핑 한국어 요약
   - `generate_candidates.py` : 후보 데이터 생성 스크립트

   터미널에서 `python roommate_match_chat.py` 를 실행하면
   웹 없이 채팅만으로 전 과정을 진행할 수도 있습니다.

   GitHub에 올려두었고, Streamlit Cloud에 배포하면
   URL 하나로 다른 사람도 쓸 수 있습니다. API 키 설정은 필요 없습니다."


--- 한계 & 개선 방향 (30초) ---

  "한계도 말씀드리면,

   후보 데이터는 **합성 데이터**라서 실제 사람과 1:1로 대응하지는 않습니다.
   채팅 파싱도 규칙 기반이라, 자유로운 문장보다는
   '남성', '20~25', '3' 같은 **짧은 답변**에 최적화되어 있습니다.

   앞으로는 실제 사용자 설문 데이터를 모으거나,
   더 많은 생활 항목—취침 시간, 게스트 초대 등—을
   추가하는 방향으로 확장할 수 있습니다."

--- 예상 Q&A (발표 후 참고) ---

  Q. 왜 API를 안 썼나요?
  A. 비용·키 관리·할당량 문제를 피하고, 폼+규칙 파싱만으로도
     데모와 실사용이 가능해서입니다.

  Q. 5,000명 데이터는 실제 사람인가요?
  A. 원본 374명 분포를 참고해 **합성 생성**한 가상 프로필입니다.

  Q. 웹 말고 다른 방식도 되나요?
  A. `roommate_match_chat.py` 로 터미널 전용 채팅 모드가 있습니다.

  Q. Streamlit Cloud 배포 시 뭘 설정하나요?
  A. Repository `minjaekim26/-8-`, Main file `app.py` 만 지정하면 됩니다.

  Q. KCI 논문 데이터는 어떻게 쓰였나요?
  A. 신지은 et al.(2017)에서 「룸메이트 행복」이 기숙사 만족의 핵심 예측 변수임을
     반영해 Happiness_Level 컬럼과 happiness 가중치(최고)를 매칭에 적용했습니다.
     상세 수치는 `kci_research_data.csv`, `KCI_FI002229041_추출.txt` 참고.
